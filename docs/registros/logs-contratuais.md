# Logs contratuais

Registros exigidos pela documentação (seção 2.2). Cada linha é um fato datado e comprovável por escrito. Não preencher de memória: anexar o e-mail, a mensagem ou o documento e registrar o caminho.

**Convenções**

- Datas no formato `AAAA-MM-DD` ou `DD/MM/AAAA`, sempre iguais ao longo do arquivo.
- **Dias úteis**: a documentação não define a convenção de feriados. Registrar aqui a convenção adotada quando for acordada com o cliente: _a definir_.
- Nenhuma comunicação ao cliente é enviada sem autorização expressa da CONTRATADA. As colunas "enviada por" e "canal" descrevem o que realmente aconteceu.
- Não registrar senhas, chaves de API nem segredos. Registrar só data, canal e responsável.
